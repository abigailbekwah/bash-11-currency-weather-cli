# bash-11-currency-weather-cli

Bash-11-currency-weather-cli is built for freelancers in camerron who get paid in dollars and euros to carry out their exchange rate successfully and determine the weather condition of the city before planning their day.

## Problem_Statement​

Freelancers in Cameroon get paid in dollars and euros, and plan their day around the rain. Build fx.sh, a currency converter that uses live exchange rates, and meteo.sh, a weather tool for any city.

## 📌 Project Goals​

- Modular Architecture: Extracting shared utility logic into a standalone library (lib.sh) to eliminate code repetition across multiple CLI tools (fx.sh and meteo.sh).

- Hardened Error Handling: Standardizing process exits and user feedback via a central die() helper function to return proper exit status codes (1 for system/network failures, 2 for invalid inputs).

- Resilient Network Request Management

- Input Validation & Sanitization

- Streamlined JSON Parsing & Math Execution
